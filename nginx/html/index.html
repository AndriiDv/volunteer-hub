Верифікація Потреб

Військові частини створюють запити на FPV-дрони, РЕБ, авто та такмед. Підтвердження облікових записів адміністратором.

🏺

Дружні Банки (Jars)

Волонтери беруть частку великого збору, підключають свої Monobank/PrivatBank банки та підтверджують збори скріншотами.

💻

Frontend Quickstart

Фронтенд розробникам: ініціалізуйте React + Vite + Tailwind у папці frontend/. Усі запити проксуються на /api.
